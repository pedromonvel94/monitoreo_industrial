# 🏭 API de Sensores Industriales

Este proyecto es una API RESTful desarrollada con **FastAPI** y **MongoDB**, diseñada para monitorear lecturas de sensores industriales (temperatura, presión y vibración). El proyecto corresponde a la actividad **EA2: Bases de datos NoSQL y operaciones CRUD**.

## 🚀 Características Principales
* **CRUD Completo:** Operaciones de creación, lectura, actualización parcial y borrado.
* **Validación Estricta:** Uso de Pydantic v2 para garantizar rangos precisos en las lecturas.
* **Persistencia NoSQL:** Conectividad robusta con MongoDB Atlas.
* **Documentación Interactiva:** Integración nativa con Swagger UI provista por FastAPI.
